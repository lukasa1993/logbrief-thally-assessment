# Inactive starter workflow examples

These files were supplied by the Thally scaffold. They are preserved as text
references, not active GitHub Actions workflows. This small assessment does not
enable scheduled framework updates, autonomous documentation agents, or upstream
runtime synchronization. The runtime itself is unchanged.

The assessment uses a small read-only validation workflow in
`.github/workflows/check.yml`, triggered only by a pull request or explicit
manual dispatch. It runs the demo tests, content check, typecheck, and build.
No scheduled jobs, repository write permissions, or saved checkout credentials
are enabled by this workflow.
